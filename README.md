## Selected projects

### [MeetMind](https://github.com/Devcodehub2004/MeetMind) — meeting audio into searchable knowledge

A meeting and video assistant that processes recordings or YouTube audio, generates transcripts and summaries, extracts action items and decisions, and answers questions using transcript retrieval. The Streamlit interface also supports document export.

**Built with:** Python, Streamlit, Whisper, Sarvam AI, LangChain, ChromaDB, and NVIDIA-hosted LLM APIs.

### [HomeSphere](https://github.com/Devcodehub2004/HomeSphere) — a personal cloud on your own server

A single-owner file storage demo with nested folders, file previews, expiring download links, and a recycle bin. It combines session-based access, PostgreSQL metadata, persistent file storage, and Alembic migrations in a local Docker Compose deployment.

**Built with:** React, FastAPI, SQLAlchemy, PostgreSQL, Alembic, Docker Compose, and Nginx.

### [OpenLLM Studio](https://github.com/Devcodehub2004/OpenLLM-Studio) — a local LLM chat workspace

A local chat application with streaming responses, installed-model selection, configurable conversation memory, and saved history. FastAPI connects to Ollama; SQLite stores completed conversations, and Streamlit provides the interface.

**Built with:** Python, FastAPI, Streamlit, Ollama, and SQLite.

### [NexusResearch-AI](https://github.com/Devcodehub2004/NexusResearch-AI) — search, read, write, critique

A research workflow that combines web search, page reading, report generation, and an AI critique. Its Streamlit dashboard shows pipeline progress and supports Markdown report downloads.

**Built with:** Python, LangChain, Groq, Tavily, Beautiful Soup, and Streamlit.
